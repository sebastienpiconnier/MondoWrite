# Feuille de route / Roadmap

**La liste des chantiers à venir, ce sont les issues GitHub** :
https://github.com/sebastienpiconnier/MondoWrite/issues (titres et contenu en français et en anglais).
Ce fichier ne garde que l'ordre dans lequel on compte les faire.

**The list of upcoming work lives in the GitHub issues** (titles and content in French and English). This file
only keeps the order in which we plan to tackle them.

Règles :
- une demande validée par l'auteur devient une issue (titre et contenu bilingues, étiquettes) et prend sa place
  ci-dessous ;
- le commit qui la termine dit `Closes #n` (l'issue se ferme toute seule), puis la ligne quitte cette liste ;
- un plan `docs/plan-*.md` garde le détail d'un chantier (décisions, format, pièges) ; l'issue le cite ;
- on ne cite pas le logiciel qui a inspiré une idée ; un nom de logiciel n'apparaît que pour la compatibilité
  (import Scrivener, fichiers Final Draft, Fountain) ou pour du code repris (licence, `THIRD-PARTY-NOTICES.md`).

Dernière mise à jour : 6 novembre 2026.
